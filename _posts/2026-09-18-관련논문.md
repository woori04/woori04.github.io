## [포렌식]

1. 포렌식이란?

컴퓨터 포렌식(computer forensics)은 디지털 장치에서 데이터를 수집, 분석, 보존하여 법적 절차에 사용할 수 있도록 하는 일련의 과정이다. 이는 컴퓨터 시스템, 하드 드라이브, 파일 시스템, 로그 파일 등을 조사하여 불법 활동의 증거를 찾아내는 것을 포함한다. 주요 목적은 다음과 같다:

1. **증거 수집**
    1. 컴퓨터 시스템, 하드 드라이브, 네트워크 로그 등에서 증거를 찾아낸다.
2. **증거 분석**
    1. 수집된 증거를 분석하여 사건의 전말을 밝힌다.
3. **증거 보존**
    1. 수집된 증거가 법적 절차에서 신뢰할 수 있도록 원본 상태를 유지하고, 무결성을 보장한다.
4. **법적 보고**
    1. 수사 결과를 법정에서 사용할 수 있도록 보고서를 작성해야 한다.
    
    증거 수집 - 법정까지의 과정에서 CoC 필수 숙지해야 함
    

2. 포렌식의 역사

컴퓨터 포렌식의 역사는 컴퓨터가 범죄에 사용되기 시작한 시점으로 거슬러 올라간다. 초기에는 컴퓨터 범죄가 드물었지만, 기술의 발전과 함께 디지털 증거의 중요성이 증가하면서 포렌식 기술도 발전하였다. 1980년대와 1990년대에는 주로 컴퓨터 해킹과 관련된 사건이 많았으며, 이 시기에 컴퓨터 포렌식 도구와 기법이 개발되기 시작했다. 2000년대 이후로는 인터넷 범죄, 데이터 유출, 사이버 테러 등의 사건이 증가하면서 포렌식 기술의 중요성도 커졌다.

3. 포렌식의 과정

증거 수집

증거 수집 단계는 디지털 증거를 찾아내고, 이를 손상되지 않도록 확보하는 과정이다. 이는 사건 현장에서 물리적인 장치를 가져오는 것부터 시작된다. 수집 과정에서는 디지털 증거의 무결성을 보장하기 위해 다양한 도구와 기법을 사용한다.

- **데이터 이미징**
    - 하드 드라이브나 다른 저장 장치의 데이터를 복제하여 원본 데이터의 무결성을 유지한다. 이를 통해 원본 데이터가 손상되거나 변조되지 않도록 한다.
- **논리적 수집**
    - 파일 시스템, 디렉토리, 특정 파일 등을 복사하여 수집한다. 이는 물리적 이미징에 비해 빠르지만, 모든 데이터를 수집하지는 않는다.
- **네트워크 데이터 수집**
    - 네트워크 트래픽, 로그 파일, 패킷 데이터를 캡처하여 수집한다. 이는 네트워크 기반의 증거를 확보하는 데 사용된다.
    

증거 분석

증거 분석 단계에서는 수집된 데이터를 분석하여 사건의 진상을 밝힌다. 여기에는 파일 시스템 분석, 로그 분석, 메모리 덤프 분석 등이 포함된다. 분석 도구로는 EnCase, FTK, X-Ways Forensics 등이 사용된다.

- **파일 시스템 분석**
    - 파일의 생성, 수정, 삭제 기록을 분석하여 사용자의 활동을 추적한다.
- **로그 분석**
    - 시스템 로그, 애플리케이션 로그 등을 분석하여 시스템의 사용 이력과 이벤트를 확인한다.
- **메모리 분석**
    - 메모리 덤프를 분석하여 실행 중인 프로세스, 네트워크 연결, 메모리 내 데이터 등을 조사한다.
    

증거 보존

증거 보존 단계에서는 수집된 증거의 원본 상태를 유지하고, 이를 법적 절차에서 사용할 수 있도록 보존한다. 해시 값 생성, 디지털 서명 등의 기법을 통해 증거의 무결성을 보장한다.

- **해시 값 생성**
    - 데이터의 무결성을 확인하기 위해 MD5, SHA-1 등의 해시 알고리즘을 사용하여 해시 값을 생성한다.
- **디지털 서명**
    - 증거의 무결성을 보장하기 위해 디지털 서명을 사용한다. 이는 증거가 변조되지 않았음을 확인하는 방법이다.
    

보고서 작성

보고서 작성 단계에서는 분석 결과를 문서화하여 법정에서 사용할 수 있도록 준비한다. 보고서에는 증거 수집 과정, 분석 방법, 결과 등이 포함된다.

- **증거 목록**
    - 수집된 증거의 목록을 작성하여 어떤 증거가 수집되었는지 명확히 한다.
- **분석 결과**
    - 분석 과정과 결과를 상세히 기술하여 법정에서 증거로 사용할 수 있도록 한다.
- **결론 및 추천 사항**
    - 분석 결과를 바탕으로 사건의 결론을 도출하고, 추가 조사나 조치에 대한 추천 사항을 제시한다.
    

4. 컴퓨터 포렌식 도구

EnCase

EnCase는 디지털 포렌식 분야에서 가장 널리 사용되는 도구 중 하나이다. 파일 시스템 분석, 이메일 분석, 네트워크 로그 분석 등의 기능을 제공하며, 다양한 파일 형식을 지원한다.

- **파일 시스템 분석**
    - FAT, NTFS, exFAT 등 다양한 파일 시스템을 지원하여 파일의 생성, 수정, 삭제 이력을 분석한다.
- **이메일 분석**
    - 다양한 이메일 클라이언트와 서버를 지원하여 이메일 메시지, 첨부 파일, 메타 데이터를 분석한다.
- **네트워크 로그 분석**
    - 네트워크 트래픽 로그를 분석하여 네트워크 활동을 추적하고, 이상 징후를 발견한다.

FTK (Forensic Toolkit)

FTK는 강력한 데이터 검색, 이메일 분석, 암호 해독 등의 기능을 제공하는 포렌식 도구이다. 특히, 대규모 데이터셋을 처리하는 데 효과적이다.

- **데이터 검색**
    - 고급 검색 기능을 통해 대규모 데이터셋에서 필요한 정보를 빠르게 찾아낸다.
- **이메일 분석**
    - 이메일 메시지와 첨부 파일을 분석하여 관련 증거를 확보한다.
- **암호 해독**
    - 암호화된 파일과 데이터베이스를 해독하여 분석할 수 있다.

X-Ways Forensics

X-Ways Forensics는 고급 분석 기능을 제공하는 도구로, 파일 시스템 분석, 데이터 복구, 디스크 이미지 생성 등의 기능을 포함한다. 경량화된 구조로 빠른 분석이 가능하다.

- **파일 시스템 분석**
    - 다양한 파일 시스템을 지원하며, 파일의 생성, 수정, 삭제 이력을 분석한다.
- **데이터 복구**
    - 삭제된 파일과 파티션을 복구하여 분석할 수 있다.
- **디스크 이미지 생성**
    - 디스크 이미지를 생성하여 원본 데이터의 무결성을 유지한다.
    

Volatility

Volatility는 메모리 포렌식 분석 도구로, 메모리 덤프에서 실행 중인 프로세스, 네트워크 연결, DLL 리스트 등을 분석할 수 있다. 이는 주로 악성 코드 분석에 사용된다.

- **프로세스 분석**
    - 메모리 덤프에서 실행 중인 프로세스를 분석하여 악성 코드의 흔적을 찾아낸다.
- **네트워크 연결 분석**
    - 메모리 덤프에서 네트워크 연결 정보를 추출하여 분석한다.
- **DLL 분석**
    - 메모리 덤프에서 로드된 DLL 리스트를 분석하여 악성 코드의 존재 여부를 확인한다.

5. 포렌식 사례

- 기업 내부자 위협
    
    한 대기업에서 중요한 기밀 문서가 유출된 사건이 발생하였다. 컴퓨터 포렌식 팀은 내부자의 컴퓨터를 조사하여, 외부로 발송된 이메일, 파일 전송 로그 등을 분석하였다. 그 결과, 특정 직원이 기밀 문서를 외부로 유출한 증거를 확보하였다.
    

- 랜섬웨어 공격
    
    랜섬웨어 공격을 받은 한 병원에서 환자 데이터가 암호화되었다. 포렌식 팀은 감염된 시스템을 분석하여 랜섬웨어의 감염 경로를 밝혀냈다. 또한, 백업 시스템에서 데이터를 복구하여 병원의 정상 운영을 지원했다.
    

- 금융 사기
    
    한 금융 기관에서 대규모 금융 사기가 발생하였다. 포렌식 팀은 관련 컴퓨터 시스템을 조사하여, 트랜잭션 로그, 이메일 통신 내역 등을 분석하였다. 이를 통해 사기 범죄에 가담한 직원과 외부 협력자들을 밝혀냈다.
    

6.포렌식 관련 법

- 증거의 수용 가능성
    
    법적 절차에서 증거로 사용되기 위해서는 증거 수집과 분석 과정이 적법해야 한다. 이는 증거의 무결성과 신뢰성을 보장하는 절차를 의미한다. 법원에서는 증거가 수집된 방식, 분석 방법, 보존 상태 등을 검토하여 증거의 수용 가능성을 판단한다.
    

- 개인 정보 보호
    
    포렌식 과정에서 개인 정보가 포함된 데이터를 다룰 때는 개인정보 보호법을 준수해야 한다. 이는 불법적인 개인정보 유출을 방지하기 위한 조치이다. 포렌식 전문가들은 개인 정보를 보호하기 위해 데이터 마스킹, 암호화 등의 방법을 사용한다.
    

- 디지털 서명과 해시
    
    증거의 무결성을 보장하기 위해 디지털 서명과 해시 값을 사용한다. 이는 증거가 조작되지 않았음을 보장하는 방법이다. 해시 값은 증거 수집 시 생성되며, 이후 분석 과정에서도 동일한 해시 값을 유지함으로써 증거의 무결성을 확인할 수 있다.
    

7.포렌식 동향

- 클라우드 포렌식
    
    클라우드 컴퓨팅의 확산으로 인해 클라우드 포렌식이 중요해지고 있다. 이는 클라우드 환경에서 데이터를 수집하고 분석하는 기술을 포함한다. 클라우드 포렌식은 데이터의 물리적 위치가 분산되어 있고, 다양한 서비스 제공자가 관여하기 때문에 복잡한 과정이다. 이를 해결하기 위해 클라우드 서비스 제공자와 협력하고, 클라우드 기반 포렌식 도구를 사용한다.
    

- 인공지능과 머신러닝
    
    인공지능과 머신러닝 기술을 활용한 포렌식 도구가 개발되고 있다. 이는 대규모 데이터 분석을 자동화하고, 분석 효율성을 높이는 데 기여한다. 예를 들어, 머신러닝 알고리즘을 사용하여 악성 코드의 패턴을 식별하고, 비정상적인 활동을 자동으로 탐지할 수 있다.
    

- 모바일 포렌식
    
    모바일 기기의 사용이 증가함에 따라 모바일 포렌식 기술이 중요해지고 있다. 이는 스마트폰, 태블릿 등의 데이터를 분석하는 기술을 포함한다. 모바일 포렌식은 다양한 운영 체제(iOS, Android 등)와 파일 시스템을 지원하며, 모바일 기기에서 삭제된 데이터도 복구할 수 있다.
    

8.포렌식 발전 방향.?

- 자동화
    
    포렌식 분석 과정의 자동화가 더욱 발전하여, 대규모 데이터셋을 신속하게 분석할 수 있을 것이다. 이는 인공지능과 머신러닝 기술을 통해 가능해질 것이다. 자동화된 포렌식 도구는 데이터 수집, 분석, 보고서 작성 등의 과정을 자동으로 수행하여 분석 시간을 단축시키고, 정확성을 높일 것이다.
    

- 통합 플랫폼
    
    여러 포렌식 도구와 기술을 통합한 플랫폼이 개발되어, 다양한 포렌식 작업을 효율적으로 수행할 수 있을 것이다. 이는 다양한 디지털 장치와 데이터 소스를 통합적으로 분석하고, 포렌식 전문가가 더 쉽게 데이터를 관리할 수 있게 해줄 것이다.
    
- 클라우드 및 IoT 포렌식
    
    클라우드 컴퓨팅과 사물인터넷(IoT) 환경에서의 포렌식 기술이 발전하여, 새로운 유형의 디지털 증거를 수집하고 분석할 수 있을 것이다. 클라우드 포렌식은 클라우드 서비스 제공자와의 협력을 통해, IoT 포렌식은 다양한 IoT 장치에서 발생하는 데이터를 분석하여 증거를 확보할 것이다.
