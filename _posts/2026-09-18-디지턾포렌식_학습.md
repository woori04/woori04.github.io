과제 : FTK 사용법 최대한 자세하게

Main 화면

Evidence Tree : 계층적 트리구조로 추가한 증거 항목을 보여준다.

File List : Evidence Tree에서 선택된 항목의 파일과 폴더를 보여준다.

File List 밑 빈칸 : Preview Mode 옵션 선택에 따라 선택된 파일의 내용을 보여준다.

Properties/Hex Value interpreter: Evidence Tree이나 File List에서 선택된 객체의 다양한 정보를 보여주고, 뷰어에 선택된 16진수 값을 10진수와 가능한 날짜, 시간 값으로 변환해서 보여준다.

Custom Content Sources : 이미지에 포함되어 있는 내용을 보여준다.

[File (왼쪽 상단)]

Add Evidence Item : 증거 자료를 Evidence Tree에 추가한다.

Create Disk Image : 디스크 이미지를 생성한다.

Image Mounting : 이미지 파일의 경로를 주고 마운트 시키면 읽기 전용 보기 옵션이 있는 물리 장치로 마운트된다.

- 마운트? 하드디스크 같은 물리적인 장치를 특정 위치, 즉 디렉토리(만 있는 것은 아님)에 연결 시켜 주는 것이다.
1. ex) 디스크를 디렉토리에 마운팅 -> 데이터를 마운트 디렉토리에 저장 -> 실제 물리적으로 디스크에 저장

Copture Memory : 메모리를 캡쳐한 결과를 저장한다.

Detect EFS Encryption : 증거를 스캔하여 암호화 된 파일이 있는지 검사한다.
