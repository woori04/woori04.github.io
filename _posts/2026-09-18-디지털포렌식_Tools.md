1. Autopsy

Autopsy는 오픈 소스 디지털 포렌식 도구로, 다양한 파일 시스템을 지원한다. 

이 도구는 Windows, macOS, Linux에서 사용할 수 있다.

- 사용법:
    1. 새 사건 생성: 분석할 새로운 사건을 만든다.
    2. 이미지 추가: 디스크 이미지 파일을 추가한다.
    3. 모듈 선택: 사용하려는 분석 모듈을 선택한다.
    4. 분석: 선택한 모듈에 따라 파일 시스템, 인터넷 기록 등을 분석한다.

2. Sleuth Kit (TSK)

- Sleuth Kit (TSK)는 디지털 포렌식 분석을 위한 명령줄 도구 세트이다. Autopsy의 백엔드로도 사용된다
- 사용법:
    1. 이미지 파일 생성
        1. `dd` 명령을 사용해 디스크 이미지 파일을 생성한다.
    2. 분석
        1.  `fls`, `ils`, `mmls` 등의 TSK 명령을 사용해 파일 시스템, 삭제된 파일 등을 분석한다.
    3. 결과 확인
        1. 분석 결과를 텍스트 파일로 저장하거나 Autopsy와 함께 사용하여 시각적으로 확인한다.
    

3. FTK Imager

FTK Imager는 무료 디지털 포렌식 도구로, 디스크 이미지를 생성하고 분석할 수 있다.

- 사용법:
    1. 디스크 이미지 생성
        1. FTK Imager를 실행하고 디스크 이미지를 생성한다.
    2. 이미지 분석
        1. 생성된 이미지를 로드하여 파일 시스템을 분석한다.
    3. 데이터 추출
        1. 필요한 파일이나 데이터를 추출한다.

4. DEFT Linux

DEFT Linux는 디지털 포렌식 및 침입 탐지를 위한 Linux 배포판으로, 다양한 오픈 소스 도구를 포함하고 있다.

- 사용법
    1. 라이브 부팅
        1. DEFT Linux를 USB나 CD로 부팅한다.
    2. 도구 선택
        1. DEFT에 포함된 다양한 포렌식 도구 중 필요한 도구를 선택한다.
    3. 분석
        1. 선택한 도구를 사용하여 디스크 이미지를 생성하고 분석한다.
    

5. Volatility

Volatility는 메모리 덤프를 분석하는 오픈 소스 포렌식 프레임워크 이다.

- 사용법
    1. 메모리 덤프 생성
        1. `dd` 명령이나 다른 도구를 사용해 메모리 덤프를 생성한다.
    2. 분석
        1. Volatility를 사용해 메모리 덤프를 분석한다
        2. `vol.py -f <메모리 덤프 파일> <명령>` 형식으로 명령을 실행한다.
    3. 결과 확인
        1. 분석 결과를 확인하고 필요한 정보를 추출한다.

Wireshark는 네트워크 트래픽을 분석하는 오픈 소스 도구이다.

    2. 캡처 시작

1. HxD

HxD는 무료 Hex 편집기 및 디스크 편집기로, 바이너리 파일, 디스크, 메모리 등을 편집할 수 있는 도구이다. 

데이터 분석과 수정에 유용하게 사용할 수 있다. 

- 사용법
    1. 파일 편집
        - 바이너리 파일, 텍스트 파일, 기타 파일 형식을 16진수로 편집할 수 있다.
        - 대용량 파일도 빠르게 로드 및 편집할 수 있다.
    2. 디스크 편집
        - 로컬 드라이브, USB 드라이브, 메모리 카드 등의 물리적 디스크를 편집할 수 있다.
        - 디스크의 특정 섹터를 직접 수정할 수 있다.
    3. 메모리 편집
        - 시스템 메모리(RAM)를 편집하여 프로세스의 메모리 상태를 실시간으로 수정할 수 있다.
        - 디버깅 및 리버스 엔지니어링에 유용하다.
    4. 검색 및 대체
        - 텍스트나 16진수 값을 검색하고, 원하는 값으로 대체할 수 있다.
        - 여러 파일에서 동시에 검색 및 대체가 가능하다.
    5. 데이터 분석
        - 파일 구조를 분석하여 특정 데이터 패턴을 식별할 수 있다.
        - 체크섬, 해시 값(MD5, SHA-1 등)을 계산하여 데이터 무결성을 확인할 수 있다.
    6. 파일 열기 및 편집
        - HxD를 실행하고 `파일 -> 열기`를 선택하여 편집할 파일을 연다.
        - 파일의 내용을 16진수와 ASCII로 표시한다. (아스키코드)
        - 원하는 위치로 이동하여 데이터를 수정한다.
    7. 디스크 열기 및 편집
        - `도구 -> 디스크 열기`를 선택하여 편집할 디스크를 선택한다.
        - 디스크의 섹터를 편집할 수 있다.
        - 주의할 것
            - 디스크 편집은 데이터 손실을 초래할 수 있으므로 주의해야 한다. (파일이 안열림)
    8. 메모리 열기 및 편집
        - `도구 -> 메모리 열기`를 선택하여 편집할 프로세스를 선택한다.
        - 프로세스의 메모리 내용을 16진수로 표시한다.
        - 원하는 위치로 이동하여 데이터를 수정한다.
    9. 검색 및 대체
        - `편집 -> 찾기`를 선택하여 검색할 값을 입력한다.
        - `편집 -> 찾기 및 바꾸기`를 선택하여 원하는 값을 다른 값으로 대체할 수 있다.
    10. 데이터 분석 및 확인
        - `도구 -> 체크섬`을 선택하여 파일의 체크섬을 계산한다.
        - `도구 -> 해시 계산`을 선택하여 파일의 해시 값을 계산한다.

## [해시]

- 해시 함수는 안전성을 갖추기 위해 지니고 있는 성질이 있다.
    - 1 역상 저항성
        - 해시 값 y를 알고 있을 때, 입력값 x가 무엇인지 알아내기 힘든 성질
        - 일방향성이라 함

- 2 역상저항성
    - 주어진 X1과 y의 값을 알고 있을 때 같은 값 y가 나오는 x2를 찾기 어려운 성질

- 충돌 저항성
    - 같은 결과값 y가 나오는 입력값 x1과 x2를 찾아내기 어려운 성질

- 해시 값은 어떤 고유한 파일만이 가지는 절대적인 값이 아닌 다른 파일이라도 동일할 수 있다.

## [법률]

**전문증거**

- 원진술자가 공판 기일 또는 심문 기일에 행한 진술 이외의 진술로서 그 주장 사실이 진실임을 입증하기 위하여 제출된 것이다.
- 경험 사실을 들은 타인이 전문한 사실을 법원에서 진술하는 경우, 경험자 자신이 경험 사실을 서면에 기재하는 경우 및 경험 사실을 들은 타인이 서면에 기재하는 경우가 포함된다.

**전문증거배제법칙**

- 전문증거는 사실 인정이라는 기초하에 경험자가 경험적 사실을 법원에 직접 보고하지 않고 다른 형태로 간접적으로 보고하는 것을 뜻한다.
- 이런 증거는 원천적으로 증거가 될 수 없다는 법칙이 전문증거배제법칙이다.
- 현재 형사소송법 제 310조의 2에 명시, 규정 되었다.

**자백배제법칙**

피고인의 자백 또는 그 피고인에게 불이익한 유일한 증거인 때는 유죄의 증거로 하지 못한다. 

- 증거 인증 과정
    - 증거 구별 → 증거 획득 → 증거 분석 → 증거 제출
